# Non-goals for the spike

This milestone does not attempt a complete Typikon, a universal Orthodox mode,
complete Great Vespers, a full calendar, all jurisdictions, translations,
liturgical text, music, notation, rendering, a web or mobile UI, a database, a
REST API, a CMS, executable pack scripts, or mature cross-language bindings.

It also does not assign a project license or claim that the example packs are
approved tradition repositories.
